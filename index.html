01 / Kapabilitas

Apa yang dapat dilakukan plugin TinyFish di ChatGPT?

01 · WEB AUTOMATION

Navigasi browser

Membuka website, menelusuri halaman, menekan tombol, dan mengisi formulir melalui agent berbasis browser.

02 · AUTHENTICATED WORKFLOWS

Profil login

Memakai Browser Context Profile untuk menggunakan sesi autentikasi yang telah disimpan, dengan batasan masa berlaku dan izin akses.

03 · EXECUTION TRACKING

Run dan status

Menjalankan tugas, memantau langkah dan status hingga selesai, serta mengembalikan ringkasan hasil ke percakapan.

04 · EVIDENCE

Capture dan observasi

Mendukung konfigurasi tangkapan layar dan rekaman saat run; ketersediaan file bukti bergantung pada hasil yang diekspos layanan.

05 · WEBSITE TASKS

Lintas aplikasi web

Berpotensi digunakan pada Odoo.sh, antarmuka Odoo ERP, GitHub, dan panel web VPS selama akses tersedia.

06 · CHAT-NATIVE

Tetap di ChatGPT Chat

Instruksi dan hasil dikelola di chat biasa melalui konektor TinyFish, tanpa harus mengalihkan percakapan ke Work.

04 / Kesimpulan

Dari percakapan menjadi tindakan.

Plugin TinyFish memungkinkan ChatGPT Chat menginstruksikan browser agent untuk melakukan pekerjaan pada website terautentikasi. Percobaan Abajoo membuktikan akses browser ke Odoo.sh dan pemeriksaan CRM pada database Odoo berhasil dijalankan.

Batas pembuktian: Uji ini membuktikan navigasi dan verifikasi status modul, bukan kemampuan memperbaiki build, mengelola SSH/VPS, atau melakukan deployment otomatis. Pengujian tersebut memerlukan POC terpisah, hak akses yang sesuai, dan kontrol keamanan.
